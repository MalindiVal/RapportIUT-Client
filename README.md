# RapportIUT‑Client

RapportIUT‑Client est le client web d’un projet de gestion et consultation de rapports pour les étudiants de l’IUT. Cette application front-end permet de visualiser, consulter et gérer des rapports en interaction avec un serveur (backend) associé.

Le projet du backend se trouve dans ce dépot : [RapportIUT-Client](https://github.com/MalindiVal/RapportIUT-API/)

## ⚙️ Fonctionnalités
- ### Connexion / Déconnexion
Authentification des utilisateurs pour accéder aux rapports.

- ### Liste des rapports
Affichage de tous les rapports disponibles avec recherche et filtrage.

- ### Consultation d’un rapport
Visualisation détaillée du contenu d’un rapport.

- ### Interface intuitive
Navigation simple et responsive pour une utilisation fluide sur ordinateur et mobile.

## 📁 Structure du projet

## 💻 Technologies utilisées
- HTML5 / CSS3
- JavaScript (Vanilla JS)

## 🚀 Installation et utilisation

### Cloner le dépôt :
- git clone https://github.com/MalindiVal/RapportIUT-Client.git
- Ouvrir index.html dans un navigateur moderne.
- Se connecter pour accéder à la liste des rapports et les consulter.

⚠️ Ce projet nécessite un backend pour récupérer les données des rapports. Assurez-vous que le serveur associé soit actif.
